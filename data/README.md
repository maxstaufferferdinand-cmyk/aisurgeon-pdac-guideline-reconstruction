# Local Data Directory

This directory is intentionally ignored except for this README.

Place required local inputs here when reproducing a pipeline step, or regenerate
them by running earlier steps. Generated CSV, JSON, JSONL, XML, manifest, audit,
state, and batch files must remain uncommitted.

The original full project with data artifacts is available locally at:

`/mnt/c/living_guideline_platform/PilotPOC`

Copy only the files required for the step you are running. See
`docs/PIPELINE.md` for script order and expected artifact names.
